# 消息流内嵌文件卡片规范

当本插件（`finder-explorer`）启用时，在以下场景中主动使用 `finder-explorer_finder` MCP 工具，方便用户在聊天消息列表里直接双击文件弹出 macOS 访达：

1. **产出交付文件后**：当你为用户生成或导出文档、报告、图片、脚本、配置文件等交付物（含工作区文件或 Artifact 产物）时，在最终汇报前调用一次 `show_files_inline`，传入最终产出文件的绝对路径列表 `paths`（以及简短 `title`），在消息流中内嵌可双击弹出访达的文件卡片。
   - 若同一任务编辑了大量内部源码文件，仅汇总用户关心的最终交付文件即可，无需在中间步骤重复调用。
2. **用户询问或查找产出文件时**：优先调用 `show_files_inline`（在当前消息流直接展示可双击卡片）或 `open_finder_browser`（在侧边栏打开完整文件浏览器）。
3. **用户明确要求在访达中打开某文件时**：直接调用 `reveal_in_finder`。
